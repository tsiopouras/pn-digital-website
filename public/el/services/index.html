Υπηρεσίες

Ιστοσελίδες για μικρές και μεσαίες επιχειρήσεις στην Κύπρο, φτιαγμένες ως γρήγορες, στατικές ιστοσελίδες φιλικές προς το κινητό.

  • Ιστοσελίδες επιχειρήσεωνΣαφείς, γρήγορες ιστοσελίδες που εξηγούν τι κάνει μια επιχείρηση και πώς να επικοινωνήσει κανείς μαζί της.
  • Ιστοσελίδες εστιατορίωνΜενού, φωτογραφίες και στοιχεία τοποθεσίας που λειτουργούν άψογα στο κινητό.
  • Ιστοσελίδες παρουσίασης έργωνΈνας σωστός χώρος για να παρουσιάσετε τη δουλειά σας, με χώρο να την εξηγήσετε.
  • Σελίδες προορισμού (landing pages)Μία εστιασμένη σελίδα για μία προσφορά ή καμπάνια.
  • Ανανέωση ιστοσελίδωνΝέος σχεδιασμός και δομή για μια παλιά ιστοσελίδα, διατηρώντας το περιεχόμενο που εξακολουθεί να λειτουργεί.
  • Πολύγλωσσες ιστοσελίδεςΣε όποια γλώσσα μιλούν οι πελάτες σας, ακόμη και σε γλώσσες που γράφονται από δεξιά προς τα αριστερά. Δείτε την εγγύηση γλώσσας.
  • Responsive σχεδιασμόςΔιατάξεις φτιαγμένες εξαρχής για κινητό, tablet και υπολογιστή.
  • Βασική ρύθμιση SEOΤίτλοι, περιγραφές, επικεφαλίδες, sitemap και τοπικά στοιχεία ρυθμισμένα σωστά.
  • Συντήρηση ιστοσελίδαςΕνημερώσεις και υποστήριξη, που συμφωνούνται ξεχωριστά για κάθε ιστοσελίδα.

Εγγύηση γλώσσας

Η ιστοσελίδα σας σε όποια γλώσσα μιλούν οι πελάτες σας.

Ελληνικά, αγγλικά, ρωσικά, ουκρανικά, εβραϊκά, αραβικά, τουρκικά, γερμανικά, γαλλικά, κινέζικα ή οποιαδήποτε άλλη γλώσσα: αν μπορεί να εμφανιστεί στο διαδίκτυο, μπορούμε να φτιάξουμε την ιστοσελίδα σας σε αυτήν. Αυτό ισχύει και για γλώσσες που γράφονται από δεξιά προς τα αριστερά, όπως τα εβραϊκά και τα αραβικά, με όλη τη διάταξη σωστά αντεστραμμένη.

Κάθε γλώσσα που επιλέγετε έχει:

  • Δικές της σελίδες, μενού και κουμπιά, όχι πρόσθετο αυτόματης μετάφρασης
  • Ρύθμιση για τις μηχανές αναζήτησης σε κάθε γλώσσα, ώστε η Google να δείχνει τη σωστή εκδοχή
  • Επιλογή γλώσσας σε κάθε σελίδα
  • Απάντηση στη γλώσσα του επισκέπτη από τον βοηθό AI, αν η ιστοσελίδα σας έχει
  • Έλεγχο κάθε μετάφρασης μαζί σας πριν δημοσιευτεί οτιδήποτε
