# Image sources

No photographs are included in this version. The build environment had no internet access, so no stock photos
could be downloaded, optimised or credited, and none were invented.

When you add photography, record every image here **before** publishing:

| File in /images | Original page URL | Photographer | Site (Unsplash / Pexels) | Licence (and link) | Date downloaded |
|---|---|---|---|---|---|

Rules: use WebP, resize to the largest size actually shown, write meaningful `alt` text, and do not use
photos that suggest the fictional demo businesses are real clients.
